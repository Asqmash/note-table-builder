# note 表づくり

note の記事に貼れる表を作るツールです。HTML 1枚だけで動きます。

**→ https://＜ユーザー名＞.github.io/note-table-builder/**

## これは何

note の記事本文は Markdown ふうに書けますが、表の記法だけ通りません。
表を入れる方法は「画像」「Gist 埋め込み」「TeX（数式記法）」の3つで、
このうち記事内のテキストとして残るのは TeX だけです。

ただし TeX を手書きするのは面倒なので、その部分を自動化しました。

## できること

- グリッドに入力すると、TeX・Markdown（Gist 用）・TSV を同時に書き出す
- Excel やスプレッドシートからコピーした範囲を、セルに直接貼りつけて取り込む
- Markdown の表を貼りつけて取り込む
- 列ごとの揃え、罫線、行の高さ（`\arraystretch`）を調整する
- セル内の改行に対応（TeX では入れ子の配列、Markdown では `<br>`）
- note と同じ KaTeX で描画したプレビューを表示する

## KaTeX で崩れる記号の自動変換

note の数式は KaTeX で描画されます。
KaTeX は日本語記事で多用する記号をそのままでは正しく組めません。

- `○ ● △ ▲ ★ ※ → × ± ① ℃` などは位置がずれる、または表示されない
  → `\bigcirc` `\textcircled{1}` などへ自動変換します（設定でオフにできます）
- `≠ ∑ ∫ ∉` など42文字はパースエラーになり、**表が丸ごと表示されません**
  → 設定に関係なく常に変換します

変換先のない文字（絵文字など）は、画面上に警告として出ます。

42文字という数は KaTeX 0.16.9 で全数チェックした結果です。
note 側のバージョンによっては前後する可能性があります。

## 貼り付け時の注意

note のエディタは複数行をまとめて貼ると段落が分かれ、数式が崩れることがあります。
その場合は「TeX（1行）」タブのインライン数式版を使ってください。

なお note のヘルプによると、iOS アプリでは数式記法が正しく動作しない場合があります。

## 使っているもの

描画プレビューに [KaTeX](https://katex.org/) を CDN から読み込んでいます。
それ以外の依存はありません。ビルドも不要です。
